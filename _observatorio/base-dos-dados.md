    <div class="sk">O que é</div>
    <h2>Um data lake nacional que já existe</h2>
    <p class="lead">A <b>Base dos Dados</b> é uma iniciativa brasileira sem fins lucrativos que padroniza e consolida bases públicas — do CadÚnico ao Enem, do RAIS ao Sistema de Informação de Nascidos Vivos, incluindo cadastros de veículos, dados eleitorais, contas municipais e centenas de datasets — em um único repositório com padrão comum de nomenclatura e formato. O acesso é aberto por SQL (BigQuery público), Python, R e download direto. É a infraestrutura de dados que a analítica pública brasileira estava esperando alguém construir.</p>
  </section>

  <section class="blk" style="border-bottom:0;padding-top:18px">
    <div class="sk">Por que importa para IA</div>
    <h2>Nenhuma IA de setor público sem dados limpos</h2>
    <p>Todo caso de IA no setor público apresentado neste portal — de Alice a CIDACS — depende do mesmo alicerce silencioso: dado limpo, integrado e acessível. Bases governamentais brasileiras existem em profusão, mas historicamente vivem em formatos incompatíveis, sistemas fechados e portais desconexos. A Base dos Dados resolve o problema de <b>arqueologia</b> que consumia 80% do tempo de qualquer projeto de analítica pública — deixando o analista livre para trabalhar no que interessa: a pergunta.</p>
  </section>

  <section class="blk" style="border-bottom:0;padding-top:18px">
    <div class="sk">O que dá para fazer</div>
    <h2>Casos de uso concretos</h2>
    <ul class="klist">
      <li><b>Cruzamento de bases</b> em minutos — CadÚnico com SIM/SINASC para efeito de programa social; RAIS com INEP para transição de escola para trabalho; contas municipais com IDH para retorno de investimento.</li>
      <li><b>Análise territorial</b> sobre milhares de municípios sem precisar coletar de cada portal municipal.</li>
      <li><b>Séries históricas longas</b> com o mesmo padrão de nome de variável ao longo dos anos — evita o tempo perdido reconciliando mudanças de layout.</li>
      <li><b>Prototipagem rápida</b> de dashboards e modelos analíticos sem depender de contratação de fornecedor para coleta.</li>
      <li><b>Ensino e capacitação</b> em analítica de políticas públicas com dado real, não fictício.</li>
    </ul>
  </section>

  <section class="blk" style="border-bottom:0;padding-top:18px;padding-bottom:20px">
    <div class="sk">O que ela ensina ao governo</div>
    <h2>Padrão que o Estado brasileiro deveria adotar</h2>
    <p class="lead">Que uma organização da sociedade civil tenha construído a infraestrutura de dados que o próprio Estado brasileiro deveria oferecer é diagnóstico do que ainda falta em governo digital: um <b>padrão</b> — de nomenclatura, formato, atualização, documentação — aplicado com disciplina através de dezenas de órgãos. O <b>Portal Brasileiro de Dados Abertos</b> (dados.gov.br) existe e tem valor, mas ainda opera muito próximo ao 'catálogo de arquivos'; a Base dos Dados opera na camada seguinte, a de <b>engenharia de dados</b> — e é onde o setor público precisa investir.</p>
